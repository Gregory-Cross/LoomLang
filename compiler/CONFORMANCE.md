## Named comparisons

The eight primary claims count each case once. For each case, the bound catalog lists the specific forms and EV clauses that the driver can observe. Each EV entry carries its revision, heading line, standing line and exact standing text from the bound evaluator file. The case headers and reverse coverage use this same list. ### pre-run

**PROPOSED.** Invocation, lexical and whole-program refusal; include invalid unused bodies. Nearest wrong outcome — Wrong cause or first offending UTF-8 byte. Group context includes B-F04–F07, B-O01/O05/O07/O08.

### value-order

**PROPOSED.** Returned values, left-to-right fields, repeated references, report-local node order and ordinary names. Nearest wrong outcome — Reversed fields or separate nodes for equal children. Group context includes B-F02/F06, B-C07, B-O04/O08.

### decimal

**PROPOSED.** Addition, truncated subtraction and multiplication of obtained naturals under the selected budgets. Nearest wrong outcome — Subtraction for addition or addition for multiplication. Group context includes B-F02, B-C02/C05/C10, B-O04/O08.

### wrong-kind

**PROPOSED.** A fully paid wrong-kind arithmetic call returns ordinary builtin none. An unpaid edge preserves its prefix. Nearest wrong outcome — Free wrong-kind edge at one-short fuel, or an invocation refusal. Group context includes B-F06/F07, B-C06/C08, B-O02/O04.

### calls-order

**PROPOSED.** Forward and recursive calls, variable reads and written argument order through the chosen stop. Nearest wrong outcome — Right argument first, or an unpaid call executed for free. Group context includes B-F05/F06, B-C04/C08, B-O02/O03.

### atomic-debit

**PROPOSED.** Earlier debits stand and the first unaffordable invoice consumes zero. Include a paid boundary counterpart. Nearest wrong outcome — An omitted debit returns a result, or a failed invoice spends fuel. Group context includes B-C02–C10, B-O02/O03/O08.

### resources

**PROPOSED.** Finite source and value caps and real file/report I/O. Account at the first failing boundary. Nearest wrong outcome — Dropping the observed limit, completed execution or failed operation. Group context includes B-F04, B-O02/O03/O06/O08.

### record-binding

**PROPOSED.** Match the actual file, argv, subject, build identity, candidate profiles and raw streams for this run. Nearest wrong outcome — A record from the adjacent source or another build, input or profile passes. Group context includes B-O03/O04/O07/O08, B-C11.
